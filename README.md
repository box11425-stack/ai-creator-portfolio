# Алексей Васютин — AI Creator Portfolio

Портфолио для позиции AI-креатора в отделе коммуникаций. Проект объединяет нейросетевые визуалы, видеомонтаж, форматные адаптации и работающие интерактивные прототипы.

## Кейсы

### 1. Villa Julia — AI Content System

Система контента из двух исходных съёмок виллы на Тенерифе:

- вертикальный UGC-ролик с обновлённой структурой и субтитрами;
- горизонтальный room tour;
- три варианта хука;
- спецификация адаптаций 9:16, 1:1 и 16:9;
- сценарные варианты для локализации.

### 2. «Цена вопроса» — Video + Product

Вертикальный ролик о юнит-экономике 3D-фигурок был пересобран в более короткий формат. К ролику добавлен интерактивный калькулятор, который считает выручку, валовую прибыль, маржу и доход за час.

### 3. «Открой больше, чем искал» — spec concept

Неофициальный концепт коммуникации для Яндекс Браузера. AI-визуал показывает браузер как точку входа в несколько возможных продолжений: знание, путешествие, творчество и действие.

Процесс: insight → концепция → prompt design → генерация key visual → отбор → адаптация форматов → motion storyboard → human review.

### 4. Creative Copilot — working MVP

Интерактивный прототип для креативной команды. Из продукта, задачи и тональности он собирает карточку гипотезы: большую идею, хук и набор форматов. В публичной версии используется локальная демонстрационная логика; подключение LLM предполагается отдельным серверным слоем.

## Что показывает проект

- генерацию и отбор нейросетевых визуалов;
- prompt design и документирование AI-процесса;
- монтаж, субтитры и адаптацию вертикального видео;
- визуализацию концептов;
- работу с форматами 16:9, 1:1 и 9:16;
- продуктовое мышление и создание работающих прототипов;
- аккуратную маркировку концептуальных проектов.

## Стек

React, TypeScript, Vinext, CSS, FFmpeg, AI image generation.

## Важно

Кейс для Яндекс Браузера является самостоятельным spec concept и не создавался по заказу Яндекса. Видео Villa Julia используются в рамках портфолио владельца материалов.
